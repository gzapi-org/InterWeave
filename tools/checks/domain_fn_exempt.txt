# Public domain functions and types with no PRODUCTION caller.
#
# A test is not a caller. `authorize_outbound` had unit tests and no
# production caller, which is the whole defect this guard exists for, so
# counting tests would let the original P1 straight through. That is why
# this ledger is long: at Stage 6 most of the neutral API is written and
# not yet wired, and this is the list of what.
#
# Two kinds of entry, both qualified as `Type::name` — a bare `new` would
# exempt eighteen unrelated constructors, and `is_punitive_at` exists on
# two types.
#
#   <Type::name>  stage-N  <reason>   nothing calls it YET. The stage
#                                     that will is a DEADLINE: the check
#                                     fails once the open stage is past
#                                     it, so an entry cannot quietly
#                                     become permanent.
#
#   <Type::name>  call <expr>         it IS called from production, in
#                                     method position the check cannot
#                                     attribute to a type. `<expr>` is
#                                     the literal call, and the check
#                                     fails unless it still appears in a
#                                     production source.
#
# A bare `Type` entry (no `::`) covers a type with no production consumer
# at all: its methods are uncalled for one reason rather than several,
# and the type comes back for review as a whole when its stage opens.
#
# Stages are assigned from the canonical plan's section for the package,
# not researched per function. An entry firing a stage early costs one
# line of triage; firing late costs everything the deadline was for.
