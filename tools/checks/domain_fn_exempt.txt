# Public domain functions with no in-tree caller yet, each keyed to the
# stage that will call it.
#
# Format:  <Type::name>  <stage-N>  <reason>
#
# QUALIFIED, not bare. A bare `new` would exempt sixteen unrelated
# constructors at once, and `is_punitive_at` exists on both AddressState
# and PeerBackoff — one entry must not vouch for the other.
#
# The stage is a DEADLINE, not a note. check_domain_fns_are_called.sh
# fails once the open stage is past the one named here, so an exemption
# cannot quietly become permanent — which is the failure mode it exists
# to prevent. `authorize_outbound` was written in the stage that was
# supposed to call it and shipped uncalled anyway.
#
# Stage numbers come from the canonical plan's section for the package.
# Where the plan does not name a consumer outright, the entry records the
# earliest stage that plausibly needs it: firing early costs one line of
# triage, firing late costs everything the deadline was for.
