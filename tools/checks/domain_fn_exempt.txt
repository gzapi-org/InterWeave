# Public domain functions the check cannot see a caller for. Two kinds,
# both qualified as `Type::name` — a bare `new` would exempt sixteen
# unrelated constructors, and `is_punitive_at` exists on two types.
#
#   <Type::name> stage-N <reason>   nothing calls it YET. The stage that
#                                   will is a DEADLINE: the check fails
#                                   once the open stage is past it, so an
#                                   exemption cannot quietly become
#                                   permanent. `authorize_outbound` was
#                                   written in the stage meant to call it
#                                   and shipped uncalled anyway.
#
#   <Type::name> call <expr>        it IS called, in method position the
#                                   check cannot attribute to a type.
#                                   `<expr>` is the literal call, and the
#                                   check fails unless that text still
#                                   appears in another tracked source.
#
# The second kind exists because textual analysis cannot tell what type a
# Rust receiver has. Rather than guess — a receiver heuristic reported
# seven genuinely-called functions as uncalled — the call is written down
# and machine-anchored. It is a human claim, but not an unverifiable one:
# it goes stale on its own the moment the call site changes.
