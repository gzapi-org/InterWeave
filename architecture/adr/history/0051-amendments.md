# ADR-0051 — amendment history

Full amendment notes for [`0051-vendor-and-patch-the-autonat-v2-client.md`](../0051-vendor-and-patch-the-autonat-v2-client.md). The body reads current; this file records how it changed.

### Amendment 2026-09-18 — The owed two-Swarm test has two halves: crate-level at step 4, substrate-level at phase B

Decision 3 read: "That test is owed, and it belongs to the step that constructs these behaviours rather than to this decision, which constructs nothing." Stage 11 step 3 — the step that constructs the AutoNAT v2 client — landed as PR #89 (merge 530f4e0, 2026-09-18) without that test, so the sentence pointed at a step that was done. p2p-network-dev raised it over GZCoord the same day with the reason step 3 found: a probe needs a candidate, `AUTONAT.md` §6 refuses a loopback one and `ScopedCandidates` enforces that before the crate sees it, so on loopback the substrate's client never issues a dial request, and a test that widened §6 to make the wire move would prove a lookalike; the same suite does reach routes 2 and 3 over real sockets, so the limit is the candidate, not the harness. The one thing left unverified — whether the vendored server would dial back a non-global address — p2p-network-dev then read on PR #89: `Behaviour::new(rng)` is the server's only constructor and `handler/dial_request.rs` filters no address class, so it dials back whatever the client requested.

The decision therefore splits the owed test where the reachable candidate splits it. A **crate-level** two-Swarm test on loopback — a raw `v2::client::Behaviour` fed a loopback candidate and dialled to a raw `v2::server::Behaviour` — negotiates a genuine dial request and a genuine `Pending`, proving the crate and the retest patch. It turned out to be written already: `crates/transport/libp2p/tests/autonat_outcome_wire.rs` on PR #90 (head 4a61586 at the time of writing; three blind review rounds, nothing at P1/P2), where the first real outcome it produced exposed a classifier defect in step 3's merged adapter, so the test is that fix's proof; step 4, the step that constructs the server, cites it rather than owing it. The **substrate-level** probe and dial-back need a public candidate and remain SPIKE-004 phase B's, where the stage's closure already waits. Decision 3's body says so; the sentence about impossibility now speaks to either step's author.
